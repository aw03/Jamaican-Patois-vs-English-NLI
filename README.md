# Jamaican-Patois-vs-English-NLI
This project for the MIT 6.4610 final research paper will analyze the embedding space of models which are used for Jamaican Patois and English Natural Language Inference

## About

This repository contains the annotated datasets that are used for the project.

The final dataset used is called [jamaican-patois-with-english-translations-nli-reviewed_output.csv](datasets/jamaican-patois-with-english-translations-nli-reviewed_output.csv), which includes the ChatGPT-generated translations from English to Jamaican Patois, along with the reviewed and edited sentences by 3 fluent Jamaican Patois and English speakers to maintain translation accuracy.
